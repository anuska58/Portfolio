# Anuska Acharya | Portfolio

[View the live portfolio](https://anuska58.github.io/Portfolio/)

A responsive portfolio for my work in applied data science, UX research, statistical analysis, and interactive visualization. The site highlights completed case studies, ongoing research, professional experience, and an accepted ASIS&T 2026 paper.

## Featured case studies

### Himalayan Expedition Risk Analysis

An interactive study of 11,358 expedition records examining how season, team size, altitude, and time relate to historical outcomes.

[View the case study](https://anuska58.github.io/Portfolio/projects/himalayan-expedition.html)

### Flight Delay Analysis

A seven-part statistical analysis of 2013 New York City flights, moving from exploratory analysis through hypothesis testing and regression.

[View the case study](https://anuska58.github.io/Portfolio/projects/flight-delay-analysis.html)

### ChatGPT Image Generation UX Research

A team study of how college students use ChatGPT to generate and edit images, combining interviews, think-aloud usability testing, and SUS analysis.

[View the case study](https://anuska58.github.io/Portfolio/projects/chatgpt-image-ux-research.html)

## Built with

- Semantic HTML
- Responsive CSS
- Vanilla JavaScript
- Accessible, keyboard-friendly interactions
- GitHub Pages

No framework or build step is required.

## Run locally

From the project folder, run:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
