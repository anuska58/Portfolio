# Anuska Acharya — Portfolio

A dependency-free, responsive portfolio built with semantic HTML, CSS, and JavaScript.

## Preview locally

From this folder, run:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Structure

- The homepage keeps completed work in compact project cards with a clear “View Project” action.
- `projects/himalayan-expedition.html` and `projects/flight-delay-analysis.html` contain the full plots, methods, findings, and limitations.
- Finding tabs are keyboard accessible and progressively enhanced; every chart remains visible when JavaScript is unavailable.
- Ongoing research is labeled clearly and does not publish participant data or unfinished findings.
- The source résumé PDF is intentionally excluded from version control and deployment because it contains a personal phone number. Add a public-safe résumé later if desired.
